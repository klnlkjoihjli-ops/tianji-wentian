# 神枢·问天 功能扩展设计文档

日期：2026-06-06

## 范围

本次迭代涵盖四个功能：
1. 对话上下文记忆（轻量追问）
2. 场景联动示例问题
3. 典籍扩充（黄帝内经、伤寒论、本草纲目）
4. 提示词优化（用户确认无需大改，跳过）

---

## 功能一：对话上下文记忆

### 目标
让 AI 在回答时知道本次会话的上一轮问答，支持自然追问，不改变前端交互。

### 数据流
1. 前端发请求时携带 `sessionId`（已有，存于 localStorage）
2. `route.ts` 调用新函数 `getRecentHistory(sessionId, limit=2)`，从 Supabase `conversations` 表按 `created_at` 倒序取最近 2 条
3. 将历史格式化为纯文本摘要，拼入系统 prompt 开头：
   ```
   【本次会话历史】
   上轮问题：...
   上轮回答要点：...（取 answer 中 jiedu/diagnosis/analysis 字段，截断至200字）
   ```
4. 无历史记录时跳过，不影响现有逻辑

### 改动文件
- `src/lib/rag/retrieval.ts`：新增 `getRecentHistory()` 函数
- `src/app/api/ask/route.ts`：在 Step 3 生成前调用 `getRecentHistory()`，将结果注入 prompt

### 边界
- 只读最近 2 轮，避免 token 超限
- 摘要截断至 200 字
- `sessionId` 为空时跳过
- 数据库查询失败时静默忽略，不影响主流程

## 功能二：场景联动示例问题

### 目标
用户切换场景时，输入框下方出现 3 个对应场景的示例问题按钮，降低使用门槛。

### 交互细节
- 切换场景 → 示例按钮淡入（opacity transition）
- 点击示例 → 填入输入框，不自动提交
- 用户开始输入 → 示例按钮淡出
- 提交问题后 → 示例按钮隐藏

### 示例内容
| 场景 | 示例1 | 示例2 | 示例3 |
|------|-------|-------|-------|
| A 命理 | 今年事业运势如何 | 我属虎，婚姻何时到来 | 如何化解今年犯太岁 |
| B 养生 | 失眠多梦怎么调理 | 春季肝火旺该怎么办 | 长期久坐腰酸如何养护 |
| C 时事 | 今年全球经济形势如何 | 如何看待当前地缘政治 | AI发展对人类意味着什么 |
| D 易经 | 近期创业是否合适 | 这段感情该继续吗 | 面临重要决策需要指引 |
| E 节气 | 当前节气该如何养生 | 冬至前后饮食注意什么 | 夏季祛湿最有效的方法 |
| F 道家 | 如何做到内心平静 | 面对压力如何看开 | 人生的意义是什么 |

### 改动文件
- `public/shenshu.html`：
  - 新增 `SCENE_EXAMPLES` 配置对象
  - 新增示例按钮容器 HTML（插入输入框下方）
  - 新增 `renderSceneExamples(scene)` 函数
  - 在场景切换事件中调用该函数
  - 在 input 事件和提交事件中隐藏示例

## 功能三：典籍扩充

### 目标
将黄帝内经从25条扩充至约100条，新增伤寒论（约60条）和本草纲目精选（约80条）。

### 文件结构
```
scripts/data/
├── neijing-full.json      # 黄帝内经（素问+灵枢，约100条）
├── shanghan.json          # 伤寒论（约60条）
├── bencao.json            # 本草纲目精选（约80条）
└── (原有典籍数据内联在脚本中，保持不动)
```

### 场景归属
- 黄帝内经补充：场景 `B`
- 伤寒论：场景 `B`（六经辨证、常见方剂）
- 本草纲目：场景 `B`（日常药材食材，附功效禁忌）

### embed 脚本改动
`embed-classics.ts` 在现有内联数据基础上，新增从 JSON 文件 import 三部典籍并推入 `ALL_CLASSICS` 数组。**不迁移原有内联数据**，避免风险。

### 运行方式
扩充完成后需重新运行：
```bash
npm run embed
```
该脚本会清空旧数据后重新入库，总条目从 330 增至约 570 条。

## 实现顺序

1. **典籍数据文件**（独立，无依赖）：创建三个 JSON 文件，修改 embed 脚本
2. **对话上下文**（改后端）：retrieval.ts + route.ts
3. **场景示例**（改前端）：shenshu.html
